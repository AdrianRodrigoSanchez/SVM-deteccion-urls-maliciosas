# Detección de URLs Maliciosas con Support Vector Machine (SVM)

Proyecto de Machine Learning para la clasificación y detección de URLs maliciosas mediante el algoritmo **Support Vector Machine (SVM)**, desarrollado en Python con Jupyter Notebook.

## Descripción

El proyecto aborda un problema real de ciberseguridad: distinguir automáticamente entre URLs legítimas y maliciosas. Se aplica el algoritmo SVM sobre un conjunto de datos real, analizando las características de las URLs para entrenar un modelo capaz de clasificarlas con alta precisión.

## Contenido del notebook

- Carga y exploración del conjunto de datos
- Preprocesamiento y limpieza de datos
- Extracción de características de las URLs
- Entrenamiento del modelo SVM
- Evaluación del rendimiento y métricas de clasificación
- Conclusiones y análisis de resultados

## Tecnologías utilizadas

- **Python 3**
- **Scikit-learn** — Implementación del algoritmo SVM
- **Pandas** — Manipulación y análisis de datos
- **NumPy** — Operaciones numéricas
- **Matplotlib / Seaborn** — Visualización de datos
- **Jupyter Notebook** — Entorno de desarrollo

## Contexto

Este proyecto tiene especial relevancia en el campo de la ciberseguridad, donde la detección automatizada de URLs maliciosas es una herramienta clave para la prevención de ataques de phishing y malware.

## Instalación y uso

1. Instala las dependencias:

```bash
pip install scikit-learn pandas numpy matplotlib seaborn jupyter
```

2. Abre el notebook:

```bash
jupyter notebook Support_Vector_Machine_-_Detección_de_URLs_maliciosas.ipynb
```
